# Materialet e JavaScript

Këtu do t'i gjeni materialet për t'u përgatitur për **Ore Sfiduese**, ose thjesht për të praktikuar vetë kur të doni.

## Struktura

```
Ora-1-GitHub/
  └── Ora-1-GitHub-Udhezues.md

Ora-2-Console/
  ├── Ora-2-Console-Udhezues.md
  ├── perseritje.html
  └── perseritje.js

Ora-3-Variablat/
  ├── Ora-3-Variablat-Udhezues.md
  ├── switch.html
  └── switch.js

Ora-4-Operatoret/
  └── Ora-4-Operatoret-Udhezues.md
  ├── operatoret.html
  └── operatoret.js

Ora-4-If-Else/
  └── Ora-4-If-Else-Udhezues.md
  ├── if-else.html
  └── if-else.js

```

Çdo folder ka një dokument **`-Udhezues.md`** me shpjegimin e koncepteve, shembuj kodi, dhe ushtrime. Kur folderi ka edhe skedarë `.html` dhe `.js`, ato janë për të kodifikuar së bashku me udhëzuesin — hapini `.html`-in në browser dhe `.js`-in në editorin tuaj.

## Si t'i përdorni

Lexoni udhëzuesin e orës përkatëse, provoni shembujt vetë, dhe mos ngurroni t'i ndryshoni vlerat për të parë çfarë ndodh — mënyra më e mirë për të mësuar është duke eksperimentuar.
