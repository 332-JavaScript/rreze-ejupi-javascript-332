# Materialet e JavaScript

Këtu do t'i gjeni materialet për t'u përgatitur për **Ore Sfiduese**, ose thjesht për të praktikuar vetë kur të doni.

Çdo folder ka një dokument **`-Udhezues.md`** me shpjegimin e koncepteve, shembuj kodi, dhe ushtrime. Kur folderi ka edhe skedarë `.html` dhe `.js`, ato janë për të kodifikuar së bashku me udhëzuesin — hapini `.html`-in në browser dhe `.js`-in në editorin tuaj.
